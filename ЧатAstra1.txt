Открыл репозиторий и прочитал текущий код, отвечающий за создание сайтов, БД и работу с сертификатами. Предыдущие ответы были не по вашему проекту: вместо изучения исходников я предложил шаблоны. Исправляю подход — продолжаем существующую программу, а не пишем отдельную автоматизацию Selenium.

Что установлено по исходникам
В репозитории приложение C# / WPF, .NET 8, а PowerShell используется для внесения изменений и сборки. Продолжим именно так.

Прочитал:

Services/IspmanagerAutomationService.cs;
Services/DatabaseDeploymentService.cs;
MainWindow.Build7.cs;
MainWindow.Build10.cs;
FIX_INPUT.txt, ispmanager-acme-devel.xml и часть материалов предыдущего исправления BUILD9.
Архивы и все исторические копии целиком не проверял. Ниже — выводы именно по текущим файлам, а не по предположениям.

1. Создание сайта не завершает ваш сценарий
Сейчас CreateWebDomainAsync() отправляет:

["site_name"] = domain,
["site_aliases"] = aliases,
["site_ssl"] = "on",
["site_cache"] = "off"

Но затем только проверяет наличие имени в списке сайтов.

В этом методе:

нет вызова letsencrypt.generate;
нет выбора Wildcard;
нет проверки сохранённых псевдонимов;
существующий домен сразу считается успешным, даже если его настройки не соответствуют заданию;
settings.Owner проверяется, но в запрос создания не передаётся.
site_ssl=on не означает, что Wildcard-сертификат выпущен.

При этом заменять site_name на domain_name вслепую нельзя: параметры страницы выпуска сертификата не доказывают, как называется поле формы создания сайта.

2. Реквизиты БД читаются не из блока db
В DatabaseDeploymentService.cs:

var databaseName = ReadPhpValue(configText, "name");
var databaseUser = ReadPhpValue(configText, "user");
var databasePassword = ReadPhpValue(configText, "pass");

ReadPhpValue() ищет первое совпадение во всём config.php. Если выше блока db есть другой name, программа может взять его.

Кроме того, host вообще не читается. Серверный клиент MySQL запускается с настройками подключения по умолчанию.

3. Ошибка подключения ошибочно трактуется как отсутствие БД
Текущий порядок:

SELECT 1 не прошёл
→ пробовать db.edit с elid
→ при любой ошибке редактирования пробовать создание

Это неправильно. Ошибка подключения может означать неверный пароль, другой сервер, отсутствие прав или недоступный MySQL — не только отсутствие базы.

Именно такой порядок способен приводить к exists(name).

Дополнительно:

сервер БД жёстко задан как server="MySQL";
используется непроверенный для вашей формы elid=имя_БД;
stderr проверки подключения подавляется;
после любой неудачи программа сообщает о несовпадении пароля, не установив настоящую причину.
4. Импорт SQL написан, но до него можно не дойти
Сервис уже умеет:

находить SQL в папке результата;
загружать его через SFTP в закрытый временный каталог;
запускать импорт на сервере;
проверять код завершения.
Поэтому отдельный mysql.exe на Windows и открытие MySQL наружу для существующей архитектуры не нужны.

Исправлять необходимо подготовку БД и проверку доступа перед импортом. Также нужна защита от непреднамеренного повторного импорта в уже заполненную базу.

5. Общий запуск может продолжать работу после ошибки
В текущем MainWindow.Build7.cs общий процесс вызывает обработчики async void, ждёт изменения _isRunning и увеличивает счётчик выполненных этапов.

Ожидание завершения не означает получение результата операции. Нужно вызывать методы, возвращающие Task, и останавливать последовательность при ошибке.

6. Проверка DNS в BUILD10 частично отключена
В Build10VerifyAcmeRecords() проверки заменены комментариями, но вызывающий код продолжает писать «обновлены и проверены».

Это нужно исправить. Для Wildcard необходима DNS-01-проверка; нажатие «Выпустить» может только запустить процесс и привести к ожиданию TXT.

Что делаем сейчас
Исходники у меня уже есть — повторно присылать их не нужно. Не хватает фактической схемы трёх форм вашей установленной версии ISPmanager.

В репозитории есть ответ webdomain.letsencrypt.txt, но это не схема создания сайта, выпуска сертификата или создания БД.

Чтобы больше не подбирать названия параметров наугад, ниже — полная команда диагностики через уже используемый программой API.

Она:

работает в Windows PowerShell 5.1 и PowerShell 7;
авторизуется вашим логином;
запрашивает site.edit, letsencrypt.generate, db.edit без sok=ok;
сохраняет имена полей, подписи и варианты выбора;
не создаёт сайты, БД и сертификаты;
не отправляет SQL;
не сохраняет пароль или идентификатор сессии в отчёт;
не изменяет исходники.
Запускайте в новом окне PowerShell, особенно если ранее выполняли команды, отключающие проверку TLS.

Полностью вставьте этот блок в PowerShell
& {
    $ErrorActionPreference = 'Stop'

    Add-Type -AssemblyName System.Net.Http

    $reportDirectory = Join-Path `
        ([Environment]::GetFolderPath('Desktop')) `
        ('ISPmanager-Schema-' + (Get-Date -Format 'yyyyMMdd-HHmmss') +
         '-' + [Guid]::NewGuid().ToString('N').Substring(0, 6))

    New-Item -ItemType Directory -Path $reportDirectory | Out-Null

    $panelText = Read-Host @'
Адрес панели с действительным HTTPS-сертификатом
Enter = https://185.115.33.18:1500/ispmgr
'@

    if ([string]::IsNullOrWhiteSpace($panelText)) {
        $panelText = 'https://185.115.33.18:1500/ispmgr'
    }

    $panelUri = $null
    if (-not [Uri]::TryCreate(
        $panelText.Trim(),
        [UriKind]::Absolute,
        [ref]$panelUri
    )) {
        throw 'Некорректный адрес панели.'
    }

    if ($panelUri.Scheme -ne 'https' -or $panelUri.UserInfo) {
        throw 'Нужен HTTPS-адрес без логина и пароля внутри URL.'
    }

    $builder = [UriBuilder]::new($panelUri)
    $builder.Query = ''
    $builder.Fragment = ''

    $panelPath = $builder.Path.TrimEnd('/')
    if (-not $panelPath.EndsWith(
        '/ispmgr',
        [StringComparison]::OrdinalIgnoreCase
    )) {
        $panelPath += '/ispmgr'
    }

    $builder.Path = $panelPath
    $panelUrl = $builder.Uri.AbsoluteUri

    $domain = (Read-Host 'Домен из папки результата, например bet123.cfd').Trim()
    $domain = $domain.TrimEnd('.')

    try {
        $domain = ([Globalization.IdnMapping]::new()).
            GetAscii($domain).ToLowerInvariant()
    }
    catch {
        throw 'Не удалось преобразовать доменное имя.'
    }

    $domainPattern = '^(?=.{1,253}$)(?:[a-z0-9](?:[a-z0-9-]{0,61}[a-z0-9])?\.)+[a-z0-9](?:[a-z0-9-]{0,61}[a-z0-9])?$'

    if ($domain -notmatch $domainPattern) {
        throw 'Укажите только доменное имя, без https://, пути и *.'
    }

    $owner = Read-Host 'Владелец сайта в ISPmanager; Enter = www-root'
    if ([string]::IsNullOrWhiteSpace($owner)) {
        $owner = 'www-root'
    }
    $owner = $owner.Trim()

    $credential = Get-Credential -Message 'Логин и пароль ISPmanager'
    if ($null -eq $credential) {
        throw 'Авторизация отменена.'
    }

    $handler = [System.Net.Http.HttpClientHandler]::new()

    # Не отправляем учётные данные по перенаправлению на другой адрес.
    $handler.AllowAutoRedirect = $false

    # Проверка сертификата НЕ отключается.
    $client = [System.Net.Http.HttpClient]::new($handler)
    $client.Timeout = [TimeSpan]::FromSeconds(90)
    $client.DefaultRequestHeaders.UserAgent.ParseAdd(
        'TextFileProcessor-SchemaDiagnostics/1.0'
    )

    function Invoke-IspReadForm {
        param(
            [Parameter(Mandatory = $true)]
            [hashtable] $Parameters
        )

        $dictionary =
            [Collections.Generic.Dictionary[string,string]]::new()

        foreach ($key in $Parameters.Keys) {
            $dictionary.Add([string]$key, [string]$Parameters[$key])
        }

        $content = [System.Net.Http.FormUrlEncodedContent]::new(
            $dictionary
        )
        $response = $null

        try {
            $response = $client.PostAsync(
                $panelUrl,
                $content
            ).GetAwaiter().GetResult()

            if (-not $response.IsSuccessStatusCode) {
                throw ('Панель вернула HTTP {0}. Проверьте адрес и доступ.' -f
                    [int]$response.StatusCode)
            }

            $body = $response.Content.ReadAsStringAsync().
                GetAwaiter().GetResult()

            $xmlSettings = [System.Xml.XmlReaderSettings]::new()
            $xmlSettings.DtdProcessing =
                [System.Xml.DtdProcessing]::Prohibit
            $xmlSettings.XmlResolver = $null

            $stringReader = [System.IO.StringReader]::new($body)
            $xmlReader = $null

            try {
                $xmlReader = [System.Xml.XmlReader]::Create(
                    $stringReader,
                    $xmlSettings
                )
                $document = [System.Xml.XmlDocument]::new()
                $document.XmlResolver = $null
                $document.Load($xmlReader)
            }
            finally {
                if ($null -ne $xmlReader) {
                    $xmlReader.Dispose()
                }
                $stringReader.Dispose()
            }

            if ($document.DocumentElement.LocalName -ne 'doc') {
                throw 'Вместо API XML получена другая страница.'
            }

            $apiError = $document.SelectSingleNode('/doc/error')
            if ($null -ne $apiError) {
                # Сырой ответ не выводим: он может содержать реквизиты.
                throw ('ISPmanager вернул ошибку для функции {0}. ' +
                       'Проверьте её доступность для этой учётной записи.' -f
                       $Parameters['func'])
            }

            return ,$document
        }
        finally {
            if ($null -ne $response) {
                $response.Dispose()
            }
            $content.Dispose()
        }
    }

    function ConvertTo-SafeFormSchema {
        param(
            [System.Xml.XmlDocument] $Document,
            [string] $FunctionName
        )

        $labels = @{}

        foreach ($message in $Document.SelectNodes(
            '/doc/messages/msg[@name]'
        )) {
            $labels[$message.GetAttribute('name')] = $message.InnerText
        }

        $fields = @(
            foreach ($node in $Document.SelectNodes(
                '/doc/metadata/form//*[@name]'
            )) {
                $name = $node.GetAttribute('name')

                [pscustomobject]@{
                    Element = $node.LocalName
                    Name    = $name
                    Type    = $node.GetAttribute('type')
                    Label   = $labels[$name]
                }
            }
        )

        $lists = @(
            foreach ($list in $Document.SelectNodes('/doc/slist')) {
                $name = $list.GetAttribute('name')

                if ($name -match '(?i)pass|secret|token|auth|session') {
                    continue
                }

                [pscustomobject]@{
                    Name = $name
                    Options = @(
                        foreach ($option in $list.SelectNodes('./val')) {
                            [pscustomobject]@{
                                Key  = $option.GetAttribute('key')
                                Text = $option.InnerText
                            }
                        }
                    )
                }
            }
        )

        # Только явно разрешённые значения по умолчанию.
        # Пароли, auth, cookie и другие произвольные данные сюда не входят.
        $allowedDefaults = @(
            'site_name', 'site_aliases', 'site_ssl', 'site_cache',
            'domain_name', 'aliases', 'owner', 'username', 'user',
            'server', 'charset', 'wildcard', 'cert_type',
            'crtname', 'email', 'from_webdomain'
        )

        $defaults = [ordered]@{}

        foreach ($name in $allowedDefaults) {
            $node = $Document.SelectSingleNode('/doc/' + $name)

            if ($null -ne $node) {
                $defaults[$name] = $node.InnerText
            }
        }

        [pscustomobject]@{
            Function = $FunctionName
            Fields   = $fields
            Lists    = $lists
            Defaults = $defaults
        }
    }

    $sessionId = $null
    $plainPassword = $null
    $authParameters = $null

    try {
        Write-Host "`nАвторизация..." -ForegroundColor Cyan

        $plainPassword = $credential.GetNetworkCredential().Password

        $authParameters = @{
            out      = 'xml'
            func     = 'auth'
            username = $credential.UserName
            password = $plainPassword
        }

        $authDocument = Invoke-IspReadForm -Parameters $authParameters
        $authNode = $authDocument.SelectSingleNode('/doc/auth')

        if ($null -eq $authNode) {
            throw 'ISPmanager не вернул идентификатор API-сессии.'
        }

        $sessionId = $authNode.GetAttribute('id')

        if ([string]::IsNullOrWhiteSpace($sessionId)) {
            $sessionId = $authNode.InnerText.Trim()
        }

        if ([string]::IsNullOrWhiteSpace($sessionId)) {
            throw 'Получен пустой идентификатор API-сессии.'
        }

        $authParameters.Clear()
        $plainPassword = $null
        $authDocument = $null
        $authNode = $null

        $requests = @(
            @{
                Function = 'site.edit'
                Extra = @{
                    plid     = ''
                    tconvert = 'punycode'
                }
            },
            @{
                Function = 'letsencrypt.generate'
                Extra = @{
                    domain_name    = $domain
                    aliases        = "www.$domain *.$domain"
                    crtname        = "${domain}_le1"
                    email          = "webmaster@$domain"
                    from_webdomain = 'on'
                    username       = $owner
                }
            },
            @{
                Function = 'db.edit'
                Extra = @{
                    plid = ''
                }
            }
        )

        foreach ($request in $requests) {
            $functionName = $request.Function

            Write-Host (
                'Чтение схемы {0}, без отправки формы...' -f $functionName
            ) -ForegroundColor Cyan

            $parameters = @{
                out  = 'devel'
                lang = 'ru'
                auth = $sessionId
                func = $functionName
            }

            foreach ($key in $request.Extra.Keys) {
                $parameters[$key] = $request.Extra[$key]
            }

            try {
                $document = Invoke-IspReadForm -Parameters $parameters

                $schema = ConvertTo-SafeFormSchema `
                    -Document $document `
                    -FunctionName $functionName

                if (@($schema.Fields).Count -eq 0) {
                    throw 'Панель не вернула описание полей формы.'
                }

                $file = Join-Path $reportDirectory (
                    $functionName + '.schema.json'
                )

                $schema |
                    ConvertTo-Json -Depth 12 |
                    Set-Content -LiteralPath $file -Encoding UTF8

                Write-Host "Сохранено: $file" -ForegroundColor Green
            }
            catch {
                Write-Warning (
                    'Не удалось получить {0}: {1}' -f
                    $functionName, $_.Exception.Message
                )
            }
            finally {
                $parameters.Clear()
            }
        }

        Write-Host "`nДиагностика закончена." -ForegroundColor Green
        Write-Host "Папка отчётов: $reportDirectory"
        Write-Host 'Ни одна форма создания не отправлялась.'
        Write-Host 'Проверьте JSON-файлы перед отправкой в чат.'
    }
    finally {
        if ($null -ne $authParameters) {
            $authParameters.Clear()
        }

        $sessionId = $null
        $plainPassword = $null
        $credential = $null

        $client.Dispose()
    }
}

Главные результаты:

Операция	Что действительно принимает ваша панель
Домен	site_name, site_aliases, site_owner
Выбор Let’s Encrypt при создании сайта	site_ssl_cert=letsencrypt, а не site_ssl=on

Важная находка: в ваших схемах уже присутствуют и пользователь bet123cfd, и база bet123cfd->MySQL. Следовательно, повторять для них «создать нового пользователя» неправильно. Но наличие БД ещё не подтверждает правильность пароля или успешный импорт.

Ниже — PowerShell-патч существующего приложения, не отдельная программа.

Что он меняет
Исправляет параметры создания сайта.
Проверяет сохранение доменного имени, владельца и псевдонимов.
Отправляет запрос на Wildcard-сертификат.
Читает реквизиты только из массива db, без исполнения PHP.
Создаёт БД через HTTPS API ISPmanager вместо неисправной команды mgrctl с паролем.
Выбирает существующего пользователя, если он уже есть.
Оставляет загрузку дампа через существующий SSH/SFTP-сервис с проверкой SSH-ключа.
Передаёт MySQL реквизиты через закрытый файл настроек, не через аргумент --password.
Не импортирует дамп поверх непустой БД.
Не сбрасывает пароли существующих пользователей.
Границы исправления: запрос сертификата и фактический выпуск — разные этапы. Если DNS обслуживает Spaceship, потребуются TXT-записи. Этот патч не объявляет сертификат выпущенным сразу после отправки запроса и не меняет DNS-зону.

& {
    $ErrorActionPreference = 'Stop'

    function Step([string]$Text) {
        Write-Host "`n=== $Text ===" -ForegroundColor Cyan
    }

    function Replace-One {
        param(
            [string]$Text,
            [string]$Pattern,
            [string]$Replacement,
            [string]$Description
        )

        $rx = [regex]::new(
            $Pattern,
            [System.Text.RegularExpressions.RegexOptions]::Singleline
        )

        $matches = $rx.Matches($Text)

        if ($matches.Count -ne 1) {
            throw (
                "Остановлено: '{0}'. Найдено совпадений: {1}, ожидалось 1. " +
                "Локальная версия отличается от изученной; исходная папка не изменена."
            ) -f $Description, $matches.Count
        }

        $m = $matches[0]

        return $Text.Substring(0, $m.Index) +
            $Replacement +
            $Text.Substring($m.Index + $m.Length)
    }

        /\*[\s\S]*?\*/|//[^\r\n]*|\#[^\r\n]*|'(?:\%%MATH_BLOCK_0%%)*'|"(?:\%%MATH_BLOCK_1%%)*"|=>|\S
        """,

    internal static DeploymentDbConfig Read(string php)
    {
        var tokens = Tokens.Matches(php)
            .Cast<Match>()
            .Select(m => m.Value)
            .Where(t => !t.StartsWith("/*", StringComparison.Ordinal) &&
                        !t.StartsWith("//", StringComparison.Ordinal) &&
                        !t.StartsWith("#", StringComparison.Ordinal))
            .ToList();

        var positions = new List<int>();

        for (var i = 0; i + 2 < tokens.Count; i++)
        {
            if ((tokens[i] == "'db'" || tokens[i] == "\"db\"") &&
                tokens[i + 1] == "=>" &&
                tokens[i + 2] == "[")
            {
                positions.Add(i + 3);
            }
        }

        if (positions.Count != 1)
            throw new InvalidOperationException(
                "Ожидался ровно один литеральный массив 'db' => [...]. " +
                "PHP-код не выполнялся.");

        var values = new Dictionary<string, string>(StringComparer.Ordinal);
        var p = positions[0];

        while (true)
        {
            if (p >= tokens.Count)
                throw new InvalidOperationException("Массив db не закрыт.");

            if (tokens[p] == "]")
                break;

            var key = Decode(tokens[p++]);

            if (p >= tokens.Count || tokens[p++] != "=>")
                throw new InvalidOperationException("Некорректный элемент массива db.");

            if (p >= tokens.Count)
                throw new InvalidOperationException("В массиве db отсутствует значение.");

            var value = Decode(tokens[p++]);

            if (!values.TryAdd(key, value))
                throw new InvalidOperationException(
                    "Повторяющийся ключ в массиве db: " + key);

            if (p >= tokens.Count)
                throw new InvalidOperationException("Массив db не закрыт.");

            if (tokens[p] == "]")
                break;

            if (tokens[p++] != ",")
                throw new InvalidOperationException(
                    "В db поддерживаются только строковые литералы. " +
                    "Конкатенация, переменные и функции не вычисляются.");
        }

        string Required(string key)
        {
            if (!values.TryGetValue(key, out var value) ||
                string.IsNullOrWhiteSpace(value))
                throw new InvalidOperationException(
                    "В массиве db отсутствует непустой параметр: " + key);
            return value;
        }

        var result = new DeploymentDbConfig(
            Required("host"), Required("name"),
            Required("user"), Required("pass"));

        // В полученной схеме зарегистрирован локальный MySQL (native).
        if (result.Host != "localhost" && result.Host != "127.0.0.1")
            throw new InvalidOperationException(
                "db.host не соответствует локальному MySQL из схемы панели. " +
                "Удалённый сервер автоматически не подставляется.");

        if (!Regex.IsMatch(result.Name, @"^[A-Za-z0-9_.-]{1,64}$"))
            throw new InvalidOperationException("Недопустимое имя базы данных.");

        if (!Regex.IsMatch(result.User, @"^[A-Za-z0-9_.-]{1,32}$"))
            throw new InvalidOperationException(
                "Недопустимое имя пользователя MySQL: разрешено до 32 символов.");

        if (result.Password.Length > 1024 ||
            result.Password.Any(char.IsControl))
            throw new InvalidOperationException(
                "Пароль БД содержит неподдерживаемые управляющие символы.");

        return result;
    }

    private static string Decode(string token)
    {
        if (token.Length < 2 ||
            (token[0] != '\'' && token[0] != '"') ||
            token[^1] != token[0])
            throw new InvalidOperationException(
                "В db ожидался строковый литерал PHP.");

        var quote = token[0];
        var result = new StringBuilder();

        for (var i = 1; i < token.Length - 1; i++)
        {
            var c = token[i];

            if (quote == '"' && c == '$')
                throw new InvalidOperationException(
                    "Интерполяция переменных PHP в db не поддерживается.");

            if (c != '\\')
            {
                result.Append(c);
                continue;
            }

            if (++i >= token.Length - 1)
                throw new InvalidOperationException("Незавершённая escape-последовательность.");

            var next = token[i];

            if (quote == '\'')
            {
                if (next == '\\' || next == '\'')
                    result.Append(next);
                else
                    result.Append('\\').Append(next);
                continue;
            }

            switch (next)
            {
                case '\\': result.Append('\\'); break;
                case '"': result.Append('"'); break;
                case '$': result.Append('$'); break;
                case 'n': result.Append('\n'); break;
                case 'r': result.Append('\r'); break;
                case 't': result.Append('\t'); break;
                case 'v': result.Append('\v'); break;
                case 'f': result.Append('\f'); break;
                case 'e': result.Append((char)27); break;
                default:
                    if (next == 'x' || next == 'u' ||
                        (next >= '0' && next <= '7'))
                        throw new InvalidOperationException(
                            "Числовые escape-последовательности PHP в db не поддерживаются.");
                    result.Append('\\').Append(next);
                    break;
            }
        }

        return result.ToString();
    }

               "user=" + Quote(user) + "\n" +
               "password=" + Quote(password) + "\n" +
               "default-character-set=utf8mb4\n";
    }
}

                name.Contains("confirm", StringComparison.OrdinalIgnoreCase))

                result[name] = value.Value;

    internal static async Task<IspmanagerOperationResult> EnsureSiteAsync(
        IspmanagerSettings settings, string password,
        string domain, CancellationToken ct)
    {
        domain = NormalizeDomain(domain);
        await SiteGate.WaitAsync(ct);

        try
        {
            using var api = await Api.Open(settings, password, ct);
            var list = await api.Call("webdomain", null, ct);

            var exists = list.Root!.Elements("elem").Any(e =>
                string.Equals(e.Element("name")?.Value?.TrimEnd('.'),
                    domain, StringComparison.OrdinalIgnoreCase));

            var request = new Dictionary<string, string>
            {
                ["out"] = "devel",
                ["tconvert"] = "punycode"
            };
            if (exists)
                request["elid"] = domain;
            else
                request["plid"] = "";

            var form = await api.Call("site.edit", request, ct);
            var fields = FormValues(form);
            var expectedOwner = settings.Owner.Trim();

            if (exists &&
                !string.Equals(Value(form, "site_owner"), expectedOwner,
                    StringComparison.Ordinal))
                throw new InvalidOperationException(
                    "Владелец существующего сайта не совпадает с настройками. " +
                    "Автоматическая смена владельца запрещена.");

            if (!exists && !Options(form, "site_owner").Contains(expectedOwner))
                throw new InvalidOperationException(
                    "Владелец отсутствует в списке site_owner панели.");

            var aliases = Value(form, "site_aliases")
                .Split(new[] { ' ', '\r', '\n', '\t', ',' },
                    StringSplitOptions.RemoveEmptyEntries)
                .ToHashSet(StringComparer.OrdinalIgnoreCase);

            var changed = aliases.Add("www." + domain);
            changed |= aliases.Add("*." + domain);

            fields["out"] = "xml";
            fields["sok"] = "ok";
            fields["tconvert"] = "punycode";
            fields["site_name"] = domain;
            fields["site_owner"] = expectedOwner;
            fields["site_aliases"] = string.Join(" ", aliases);

            if (exists)
            {
                fields["elid"] = domain;
            }
            else
            {
                fields["plid"] = "";
                fields["site_ssl_cert"] = "letsencrypt";
                fields["site_srv_cache"] = "off";
                fields["site_script_selector"] = "*";
                fields["lp_db_source"] = "db_not_use";
                fields["site_email"] = "webmaster@" + domain;
            }

            if (!exists || changed)
                await api.Call("site.edit", fields, ct);

            var check = await api.Call("site.edit",
                new Dictionary<string, string>
                {
                    ["out"] = "devel",
                    ["elid"] = domain,
                    ["tconvert"] = "punycode"
                }, ct);

            var savedAliases = Value(check, "site_aliases")
                .Split(new[] { ' ', '\r', '\n', '\t', ',' },
                    StringSplitOptions.RemoveEmptyEntries)
                .ToHashSet(StringComparer.OrdinalIgnoreCase);

            if (!string.Equals(Value(check, "site_name"), domain,
                    StringComparison.OrdinalIgnoreCase) ||
                Value(check, "site_owner") != expectedOwner ||
                !savedAliases.Contains("www." + domain) ||
                !savedAliases.Contains("*." + domain))
                throw new InvalidOperationException(
                    "Не подтверждено сохранение имени, владельца или псевдонимов сайта.");

            var stateDirectory = Path.Combine(
                Environment.GetFolderPath(Environment.SpecialFolder.LocalApplicationData),
                "TextFileProcessor", "deployment-certificate-requests");

            Directory.CreateDirectory(stateDirectory);

            var panel = new UriBuilder(settings.PanelUrl)
            {
                Query = "",
                Fragment = ""
            }.Uri.AbsoluteUri.TrimEnd('/');

            var stateKey = Convert.ToHexString(SHA256.HashData(
                Encoding.UTF8.GetBytes(panel + "\n" + expectedOwner + "\n" + domain)));

            var stateFile = Path.Combine(stateDirectory, stateKey + ".state");

            if (File.Exists(stateFile))
            {
                var state = await File.ReadAllTextAsync(stateFile, ct);

                if (state == "submitted")
                    return new IspmanagerOperationResult
                    {
                        Success = true,
                        Message = $"Сайт {domain} и псевдонимы проверены. " +
                            "Запрос Wildcard ранее отправлен этим модулем. " +
                            "Повторный выпуск не запускался; проверьте статус сертификата в панели."
                    };

                throw new InvalidOperationException(
                    "Для этого домена сохранён незавершённый запрос сертификата. " +
                    "Его исход неизвестен: проверьте ISPmanager перед повторным выпуском. " +
                    "Файл состояния: " + stateFile);
            }

            var certificateParameters = new Dictionary<string, string>
            {
                ["out"] = "devel",
                ["username"] = expectedOwner,
                ["domain_name"] = domain,
                ["aliases"] = $"www.{domain} *.{domain}",
                ["crtname"] = domain + "_le1",
                ["email"] = "webmaster@" + domain,
                ["from_webdomain"] = "on",
                ["wildcard"] = "on",
                ["dns_check"] = "on",
                ["enable_cert"] = "on"

            foreach (var pair in certificateParameters)

            certificateFields["sok"] = "ok";

            // При таймауте не отправляем повторный запрос автоматически.

            await File.WriteAllTextAsync(stateFile, "submitted", ct);

            return new IspmanagerOperationResult
            {
                Success = true,
                Message = $"Сайт {domain}, владелец и псевдонимы проверены. " +

    internal static async Task<bool> EnsureDatabaseAsync(
        IspmanagerSettings settings, string panelPassword,
        DeploymentDbConfig db, CancellationToken ct)
    {
        using var api = await Api.Open(settings, panelPassword, ct);

        // В полученной схеме site.edit список lp_db_source содержит
        // реальные ключи вида database->MySQL.
        var siteForm = await api.Call("site.edit",
            new Dictionary<string, string>
            {
                ["out"] = "devel",
                ["plid"] = "",
                ["site_owner"] = settings.Owner.Trim()
            }, ct);

        var databases = Options(siteForm, "lp_db_source");

        if (!databases.Contains("db_not_use"))
            throw new InvalidOperationException(
                "Панель не вернула ожидаемый список баз lp_db_source.");

        if (databases.Contains(db.Name + "->MySQL"))
            return false;

        var form = await api.Call("db.edit",
            new Dictionary<string, string>
            {
                ["out"] = "devel",
                ["plid"] = "",
                ["owner"] = settings.Owner.Trim(),
                ["server"] = "MySQL"
            }, ct);

        if (!Options(form, "server").Contains("MySQL") ||
            !Options(form, "owner").Contains(settings.Owner.Trim()) ||
            !Options(form, "charset").Contains("utf8mb4"))
            throw new InvalidOperationException(
                "Схема db.edit не подтвердила сервер, владельца или utf8mb4.");

        var users = Options(form, "user");
        if (!users.Contains("*"))
            throw new InvalidOperationException(
                "Панель не вернула ожидаемый список пользователей БД.");

        var parameters = new Dictionary<string, string>
        {
            ["sok"] = "ok",
            ["name"] = db.Name,
            ["owner"] = settings.Owner.Trim(),
            ["server"] = "MySQL",
            ["charset"] = "utf8mb4",
            ["remote_access"] = "off"
        };

        if (users.Contains(db.User))
        {
            parameters["user"] = db.User;
        }
        else
        {
            parameters["user"] = "*";
            parameters["username"] = db.User;
            parameters["password"] = db.Password;
            parameters["confirm"] = db.Password;
        }

        try
        {
            await api.Call("db.edit", parameters, ct);
        }
        finally
        {
            parameters.Clear();
        }

        var check = await api.Call("site.edit",
            new Dictionary<string, string>
            {
                ["out"] = "devel",
                ["plid"] = "",
                ["site_owner"] = settings.Owner.Trim()
            }, ct);
